# Newasa Food Hub V2
Flutter MVP for Android + iPhone.

Included:
- Mobile login screen (demo)
- Newasa food/restaurant listing
- Search UI
- Food categories concept
- Add to cart
- Checkout
- Cash on Delivery
- UPI/Online Payment placeholder
- Order status concept
- Profile

Run:
flutter pub get
flutter run

Build Android:
flutter build apk --release

Build iPhone (macOS + Xcode):
flutter build ipa --release

Production next:
Firebase Auth + Firestore, real restaurant data, Razorpay/UPI gateway, Maps/live tracking, push notifications, restaurant/delivery/admin panels.
